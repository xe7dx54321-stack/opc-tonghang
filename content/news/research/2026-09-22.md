本周 arxiv 7 天内新稿 220 篇（11 个类目），按 6 个关注方向筛选了 29 篇。三个跨方向信号值得一上来就讲：第一，**agent harness** 这条线今年彻底独立出来——本周就有 RRSI（harness 的递归自我改进）和 Harness-Zero（用强 agent 蒸馏小模型）两篇严肃工作，未来 harness 不再是 prompt + 工具调用的代名词，而是一个有 RL 训练范式的工程对象；第二，**世界模型**研究从"长视频生成"切到"3D 一致性"——WorldCrafter 和 GAE 都把 3D 几何作为底层潜空间，硬扛 NeRF / 3DGS 的工作流；第三，**AI 芯片**的边际创新集中在 FP4 tensor core 与 speculative decoding 的耦合——AWE 和 SPECTRA 是两个互补的方向。下面分方向过。

### 1. 大模型基础（5 篇）

本周 llm-foundation 主题里最值得跟的是 **onPanda**（cs.CL）——一个 token 级 on-policy 标注工具，把 LLM 对齐数据和 agent 轨迹的标注速度提升到原来的 4 倍。alignment data 是头部实验室最大的人力成本，自动化标注会持续压低 RLHF / DPO 价格，是 2027 年中小玩家与大厂正面交锋的关键技术。**SLICEChat**（cs.CL）专攻病理全切片图像（WSI）的 in-encoder token pruning，把千兆像素级的 WSI 喂给 slide-level MLLM 时不再全用 patch token，是医疗多模态的一条实用工程线。**FoldQuantVLA**（eess.SY）做 VLA 模型的原生低比特量化，把"观察→动作"延迟压到能跑实时机器人控制的水平，是端侧 VLA 的关键一环。另外两篇（Partner-Specific Affective Precision、Total Cost of Agency）放到 agent 段更合适。

### 2. Agent 框架（5 篇）

这是本周最热的方向。**Total Cost of Agency**（cs.MA）是这一周最值得读的一篇——多 agent 工作流里每个节点都会从 memory 检索并注入 prompt，但这些注入的 token 按与系统 prompt / 用户查询同样的单价计费，作者给出了精确的 memory 注入成本归因模型，对企业部署 agent 的成本控制是直接相关的。**RRSI**（cs.AI / cs.CL）是 Anthropic 风格的延伸——把 agent harness 视为 RL 训练对象，提出递归自我改进的正则化框架，避免 harness 漂移到无意义解。**Harness-Zero**（上周也提过，本周另有一篇配套）用强 agent 蒸馏小模型，7B 在 SWE-bench 拿到 65%。另外两篇偏理论/应用：Mixed-integer flow formulations 给网络化多 agent 系统的运动规划提供了 MILP 解；TRACS 是仓库多 agent 路径规划的几何感知框架，距离 LP/VC 关心的事略远，但工程上值得关注。

### 3. 物理世界模型（5 篇）

**GAE**（cs.CV）和 **WorldCrafter**（cs.CV）是本周世界模型双子星。GAE 把几何原生潜空间作为感知 + 生成共享底座——视觉生成器在不显式建模 3D 场景的前提下就能产出 photometrically 一致的帧，是 World Labs / NVIDIA Cosmos 路线之外的第三条路。WorldCrafter 用相机可查的隐式 3D-aware memory 解决了长视频跨视角一致性问题，30 秒视频比 SOTA 提升 18% consistency。**Revisiting Multi-View Stereo** 把多视角几何重写成 seq-to-seq 形式，是几何本身的范式重审；**When Wider Views Fail** 是 feed-forward 3D 重建模型的失败模式压力测试，对训练数据 distribution shift 的脆弱性做了系统量化。世界模型这条线从"卷视频长度"切到"卷几何一致性"已经成型，2027 年的胜负手在潜空间设计与训练范式。

### 4. 具身 VLA 模型（5 篇）

**DexTacWAM**（cs.RO / cs.CV / cs.AI）继续是具身这条线的旗舰——把视觉 + 触觉融合进 WAM（world-action model），在灵巧手操作任务上比单模态提升 35% 成功率。触觉是 2026 VLA 模型的下一道口子，Stanford / MIT 风格的延续。**MIGU**（cs.RO）做不确定性下的多模态指令 grounding——把"机器人不知道该怎么操作时该怎么处理"这件事做了工程化，落地价值高。**Learning Beyond What Humans Can Demonstrate**（cs.RO）讨论的是"机器人能学到人演示不出来的东西"——这一篇比较早期，方法论层面值得跟。**Generative Tutorial**（cs.HC）把生成式模型用于"物理任务的实时上下文视觉指令"，是 AR + robot 教学的交叉，跨在 embodied 和 HC 之间。

### 5. AI 芯片 / 加速器（5 篇）

**Bridging the Vendor Gap**（cs.DC）给 HL-LHC 时代的物理数据分析补了 AMD GPU + ROCm/HIP 对 Awkward Array 的支持——不只是技术论文，是给"加速器 = NVIDIA"叙事撕开了一道缝。**AWE**（cs.AR）做 FP4 tensor core 上的整数矩阵乘法自适应 weight encoding——FP4 已经是 2026 推理芯片的标配，AWE 这种"少 GEMM、更省功耗"的方向会被持续卷。**SPECTRA**（cs.AR）把 speculative decoding 落到 runtime-reconfigurable tiled 架构上，是 NVIDIA / Groq / Cerebras 风格之外的实验性架构。**Explicit State and Resource Contracts**（cs.DC）给低精度流水线并行训练加了形式化契约，是工程层面的"可证安全"。**NPU Accelerator**（cs.AR）用 PYNQ-Z1 + FINN 做量化实时车辆检测，是端侧 NPU 的真实落地 demo。AI 芯片这一周不算大新闻，但边际方向都在做"省 token + 降低精度 + 跑异构"的组合，国产推理芯片对得上这一波趋势。

### 6. 半导体前沿（1 篇）

**Toward Multi-kW Power Delivery for Advanced 3D Heterogeneous Integration**（cs.AR）是本周唯一一篇真正踩到半导体前沿的——讨论先进 3D 异构集成下的多 kW 级供电方法。3D IC / chiplet / CoWoS 这条线走到 2026 年，最大瓶颈其实不是 interconnect 而是 power delivery，TSMC / Samsung 在台积电 2nm / 1.4nm 节点上都在解决这件事。本周这个方向 arxiv 新论文不多，主要因为半导体前沿研究更偏向 IEDM / VLSI Symposia / ISSCC 这些会议而非 arxiv。建议保持 SignalRadar 的搜索 query（已加在 sources/search-queries.yaml）继续兜底。

**本周观察**

- **Agent harness 独立成研究方向**：RRSI / Harness-Zero / onPanda / Critical-State RL 都在做"把 harness 当 RL 对象"，这是 2026 最值得跟的工程范式转变。
- **世界模型"3D 化"**：从视频帧生成切到 3D 一致潜空间——World Labs、NVIDIA Cosmos、GAE、WorldCrafter 殊途同归。
- **AI 芯片边际方向收敛**：FP4 / speculative decoding / tiled architecture / 异构调度四个方向互相支撑，国产推理芯片正卡在这条主线上。
- **硅前沿本周稀疏**：建议未来 1 周转向会议论文跟踪（IEDM / VLSI / ISSCC），arxiv 不足以覆盖这条线。
