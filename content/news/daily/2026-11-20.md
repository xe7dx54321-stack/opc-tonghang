## Anthropic登陆纳斯达克，开盘价较发行价上涨约三成

TechCrunch 报道，Anthropic 已在纳斯达克开始交易，上市初期股价为 **111.50 美元**，较每股 83 美元的发行价高约 33%。这是此前 IPO 路演之后的新进展，不是把路演重新当作一次新上市。盘初报价只是当时的市场价格，并不代表收盘表现或未来估值。

对 AI 投资而言，上市的意义不只是多了一个市值数字：公开市场会持续检验模型收入增长、算力支出与融资需求之间的关系。高开说明当时买方愿意以更高价格参与，但它本身既不能证明模型优势可以长期维持，也不能回答资本开支何时能转化为自由现金流。后续更值得跟踪的是公开披露的收入质量、客户集中度和算力承诺，而不是把首日涨幅等同于基本面改善。

## 无涯智远获数亿元融资，押注模型参数持续学习

据《智能涌现》报道，无涯智远近期连续完成**数亿元天使轮和天使加轮融资**，投资方包括五源资本、红杉中国、联想之星等；报道没有给出两轮各自的精确金额和完成日期。资金计划用于实时 RSI 模型研发与产品落地。报道把融资完成时间写作“近日”，因此今日的新动作是媒体披露融资，而不是断言交易恰在今天完成。

公司探索的路线，是用超网络根据新增知识生成基座模型的参数更新，而不只是把资料留在上下文或检索库里。原文提到的 SHINE 是此前论文，不应视为今天新发表的研究；它提供路线背景，也不等于已经证明公司产品在真实业务环境中可用。

这个方向真正的商业问题在于：更新一次知识需要多少计算，更新后旧能力是否退化，错误知识能否撤回，以及客户如何审计模型变化。即便新知识写入参数很快，如果验证、回滚和隔离的成本很高，仍未必比检索增强或周期性微调更划算。现阶段应把技术效果视为团队路线和早期研究，而非已独立验证的生产性能。

## Gemini在Mac上获得电脑操作能力，首批限美国付费用户

Google 将 computer use 引入 Gemini 的 macOS 桌面应用。TechCrunch 报道，用户给出任务后，Agent 可以在后台操作本地应用和网站，用户能在聊天界面查看执行过程，并可暂停、停止或批准动作。首批仅面向美国英语用户，要求安装 Mac 应用并订阅 Google AI Plus、Pro 或 Ultra；其他市场与平台的时间尚未公布。

这里的新变化是 Agent 能跨过浏览器页面，进入桌面文件和原生应用。对企业软件而言，这既可能让原本没有 API 的工作流被自动化，也会把权限、隐私和审计问题直接带进终端。能演示跨应用操作并不等于能可靠完成复杂工作：用户真正需要的是明确的授权边界、动作前确认，以及操作失败后的可恢复性。

## Google预览Tool Retrieval，按需加载Agent工具参数

Google 在 Gemini Interactions API 中预览 Tool Retrieval：Agent 可以保留工具名称和描述，仅在需要时加载完整参数 schema，而不必每次都把所有工具定义送进上下文。开发者通过加入 tool_search 并设置 defer_loading 使用该功能。Google 称这有助于减少输入 token 和时延，并改善大量候选工具时的选择问题。

限制同样重要：这是预览功能，支持 Gemini 3.6 及之后的模型；工具检索没有单独收费，但工具搜索本身及加载后的 schema 仍按模型 token 计费。实际节省取决于未加载工具有多少，以及会话里反复调用的情况。厂商的效率描述并不是独立基准，采购方需要在自己的工具数量、流量与任务成功率上做对照。

[原文](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)

## AWS为SageMaker推理端点增加漂移与闲置GPU监控

AWS 介绍 SageMaker AI 推理端点的新监控与优化建议：系统观察延迟变化、闲置 GPU 和配置缺口，经 AWS Health 通知后，用户可以在独立计算资源上比较替代配置的响应时间、吞吐及成本。生产端点不会在用户未主动应用结果时自动变更。

AWS 表示，符合条件的 GPU 端点需使用 vLLM serving container，监控默认开启且可以退出；它观察运行信号，不读取请求或响应。监控和运行独立基准的成本不应混为一谈。对算力买方而言，这解决的是部署后工作负载变化造成的资源漂移，但推荐配置是否适用仍取决于真实流量，不能把厂商建议直接当作节省金额。

[原文](https://aws.amazon.com/blogs/machine-learning/amazon-sagemaker-ai-now-detects-latency-drift-idle-gpus-and-missed-optimizations-on-your-inference-endpoints/)

## 阿里云外部客户收入同比增长64%，增速较上季加快

雷峰网报道，阿里巴巴最新季度业绩显示，阿里云外部客户收入同比增长 **64%**，高于上一季度的 45%；AI 相关产品收入连续第 13 个季度实现三位数增长。这里的 64% 指外部客户收入增速，不应误写成整个集团收入或云业务利润增速。

云需求加快对国产算力生态有直接意义，但收入增长本身不能回答毛利率、资本开支回收或客户使用持续性。企业应继续看订单向实际消耗的转化，以及新增资源利用率；投资人则应区分一次性扩容带来的需求与稳定、可复购的生产工作负载。

## Meta员工反馈Muse混淆会话，隐私边界受到质疑

TechCrunch 转述路透对 Meta 内部员工帖子的报道：员工称 Muse 出现会话混淆，展示了他们没有提出的请求，以及不属于自己的银行账户余额等信息。报道反映的是员工反馈，不能据此断言公众版本发生了同样规模的泄漏。

Meta 对 TechCrunch 表示，员工测试用于发现问题并改进安全与隐私保护，员工接触的 Muse 版本与公众版本不同。对投资者和产品团队，值得追问的是跨账号隔离、长期记忆和第三方应用授权能否被独立审计；更强的主动性会扩大可访问数据的范围，也提高一次错误关联的代价。
