[World model companies are keeping a lot of secrets](https://techcrunch.com/) 把 world model 赛道的"封闭性"摆到了台面上。TC 报道 World Labs / Decart / Odyssey 三家都在过去 6 个月切到了"非公开 demo + 投资人专属通路"——这跟 2023-2024 大家抢发 YouTube demo 的开放格局完全相反。本质原因是：训练一个 SOTA world model 的成本从 2023 年的百万美元级跳到了 2026 的千万级，公开 demo 一次烧 50-100 万美金，公司选 minimize shareholder dilution 而非 PR。这一波对早期投资人有两个信号：一是估值锚定从"开源可复现"切到"路线图信仰"，二是退出路径更依赖被 NVIDIA / Google 收购而非 IPO。

[MCP was always a bad idea?](https://simonwillison.net/) 是 Simon Willison 这一周最重要的一条评论。MCP（Model Context Protocol）在过去一年从 Anthropic 推动变成行业事实标准（OpenAI、Google 都接入），但 Simon 这条直指其结构性缺陷：MCP 把"工具调用上下文"作为协议核心，但在 agent 实际运行时，工具上下文与对话上下文是分裂的——前者是 deterministic 的（schema 固定），后者是 stochastic 的（LLM 生成），两者通过 MCP 强行拼装会带来"幻觉传递"风险。这一波观点预计会引出 MCP v2 的设计讨论，OpenAI / Anthropic 都可能需要重新审视协议层。
