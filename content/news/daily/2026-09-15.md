2026 年 9 月 15 日，周一。本周 AI 圈的开场被两件事抢走——Google 推出 Gemini 3.8 Live，把语音 / 视频多模态实时推理推到了消费级；同一周晚些时候 NVIDIA 在 Dreamforce 上让黄仁勋以"Now we can know everything and do anything"为题做了一场半年度定位演讲。两条都不算新闻级事件，但它们一起给"基础模型 → 实时 agent → 通用推理"这条线定了一个时间锚。

[Google 推出 Gemini 3.8 Live + Extended Thinking](https://deepmind.google/) 是这一周最值得记下来的产品节点。3.8 Live 把 Gemini 的实时语音 + 视频流推理从开发者预览升到 GA，Extended Thinking 给了开发者可控的"思考预算"开关——这两个一起等于把"实时 + 慢思考"两个过去冲突的范式合并到一个模型里。DeepMind 的口径仍然是 o3-mini 同档推理性能，但工程上更接近 Anthropic 的 extended thinking API。短看对 ElevenLabs 这类实时语音栈是压力，长看对 OpenAI Realtime API 是定价压力。

黄仁勋在 Dreamforce 的演讲 ([Jensen Huang at Dreamforce](https://blogs.nvidia.com/)) 把"AI 是新一代工业革命"这条线讲到了极致，但真正能落地的还是他同步公布的两个数字：Blackwell Ultra 出货量比上季度翻倍、HGX B200 在云客户中的部署速度是上一代 H100 的 5 倍。这两个数字对二级市场是直接利好——下周 NVDA 财报前机构大概率已经 price in，但我们想跟的不是 GPU 销量本身，而是"AI 推理工作负载从训练转向推理"这一结构性变化何时被市场完全反映。

[Show HN: Relay](https://hnrss.org/) 这种 self-hosted LLM gateway 这周在 HN 首页反复出现——Relay / OnPanda / Slowave / Pizza Bot / Scry 五个 Show HN 全部是"本地化 agent 基础设施"方向。从 LLM gateway（流量整形）到 token 级 steer（OnPanda）到本地 adaptive memory（Slowave），说明 2026 Q3 的创业重心已经从"再做一个 LLM"切到"让本地 agent 跑得动"。这一波对独立 LLM 玩家是利空——API 不再是大模型唯一的部署形态。
