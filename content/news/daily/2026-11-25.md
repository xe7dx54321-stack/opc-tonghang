今天值得连起来看的是 AI 从“回答”转向实际工作时的配套设施：企业如何保留数据和审查权，Agent 怎样处理长任务，生成的应用又怎样进入桌面。与此同时，自动驾驶正在验证撤掉安全员后的运营能力；机器人训练和小型硬件融资提醒我们，技术演示与可持续交付之间仍有距离。

## AWS 推出 Bedrock 可信访问 API，Claude 企业安全控制进入预览

AWS 宣布 Amazon Bedrock 的 **Trusted Access API 正式可用**，企业可以通过统一入口发现、申请并加入模型提供方的可信访问项目。第一批提供的是与 Anthropic 合作的 Enterprise Frontier Safeguards（EFS）和 Enterprise Data Controls（EDC），目前均为公开预览，而不是已经对所有客户无条件开放的正式服务。

AWS 称，各项目有自己的适用资格、审批流程和条款；管理者可用 IAM 等既有权限体系控制谁有权加入。EFS 的设计是让客户把数据保留在自己的 AWS 环境，自动化系统仍进行安全监测，相关审查交由客户处理；AWS 也说明，若所需的密钥或存储访问被撤销，覆盖模型的服务会在一定时间后停止。这不是“无需安全监控”，而是在既有安全要求下重新划分数据保管与人工审查的责任。

对于金融、医疗等敏感行业，采购决定越来越不像单纯比较模型排行榜：能否解释谁可以访问提示词、异常如何复核、责任由谁承担，直接影响能否上线。值得关注的是试点范围能否扩大以及客户实际承担多少审查成本；预览发布本身不能证明这些方案已经满足每家企业的合规要求。

来源：[AWS 原文](https://aws.amazon.com/blogs/machine-learning/introducing-the-amazon-bedrock-trusted-access-api-with-anthropics-enterprise-frontier-safeguards-and-enterprise-data-controls/)

## 百度开源文心 5.5 Flash Preview，采用 Apache 2.0 协议

雷峰网报道，百度开放 **ERNIE 5.5 Flash Preview** 的模型权重和配套资源，采用 Apache 2.0 协议，可通过 Hugging Face、ModelScope 获取，并支持 vLLM、SGLang 等推理框架。报道给出的规模是总参数 2800 亿、每个 token 激活 140 亿，最长上下文为 100 万 token。

这个组合瞄准的是既需要较大模型能力、又在意推理资源的部署方。总参数和激活参数应分开看：后者与单次计算有关，前者仍会影响权重存储、设备配置及部署方式。长上下文标称值也不等于所有长度下的检索质量、吞吐或成本都已得到独立验证。

对企业和开发者而言，开放权重的直接意义是可以评估本地或自托管部署，而不必只依赖厂商托管接口；但真实采用还要看目标任务的独立评测、具体硬件成本和维护能力。报道中的榜单成绩属于来源转述，不能直接视为长期、跨任务的领先结论。

来源：[雷峰网原文](https://www.leiphone.com/category/industrynews/X2LHtIreyiO6depw.html)

## Anthropic 扩展 MCP：后台任务和交互正式可用，Skills 进入测试

The Decoder 报道，Anthropic 将 MCP 的 **Tasks 和 Elicitation 推至正式可用**。前者允许服务器运行较长的任务、完成后返回结果；后者允许任务进行中向用户索取缺失信息。此前的工具调用更容易被理解为一次请求与一次响应，而这两个能力面向的是会等待、需要补充输入的多步骤工作。

另一个变化是 Skills over MCP 进入公开测试：服务器可把工具和特定工作说明配合提供，技能按需加载。报道还提到文件上传支持即将推出；它是计划中的能力，不应与已经正式可用的任务功能混为一谈。企业侧的服务器管理与授权也会影响最终能否安全使用。

值得观察的不是协议名称出现了多少次，而是开发者能否处理任务取消、失败恢复、权限与审计等真正的生产问题。长任务可以减少用户守在对话框前的时间，也把状态管理和信任边界变成产品的核心成本。

来源：[The Decoder 原文](https://the-decoder.com/anthropic-tops-700-million-monthly-mcp-sdk-downloads-and-expands-the-protocol-for-more-autonomous-ai-agents/)

## Uber、Nuro 与 Lucid 在湾区启动无安全员道路测试

据 The Verge，Uber、Nuro 和 Lucid 开始在旧金山湾区公共道路上进行 **车内无安全员测试**，随后计划提供仅面向员工的乘车服务。测试先覆盖 Palo Alto、Mountain View、Los Altos 和 Sunnyvale 等南湾城市，使用搭载 Nuro 自动驾驶系统的 Lucid Gravity 车辆。

这一动作与面向公众的商业运营是两个不同节点。报道说，原计划在 2026 年底向公众开放的服务现预计推迟到 2027 年初；测试前，合作方已经在湾区和休斯敦进行近一年的有人监督测试。报道还称 Lucid 已交付超过 100 辆升级版车辆，但交付测试车辆不等于取得同等规模的付费订单。

去掉车内安全员意味着团队开始检验更接近实际运营的系统，但投资人接下来仍要看限定区域内的接管与远程支持、监管许可、车辆利用率和真实单位经济。三家公司分别承担平台、自动驾驶系统和整车角色，也意味着商业化结果最终取决于整条协作链，而非单一模型能力。

来源：[The Verge 原文](https://www.theverge.com/transportation/1040676/uber-nuro-lucid-driverless-robotaxi-testing-bay-area)

## Claude Artifacts 支持安装为桌面应用，功能仍处测试阶段

The Decoder 报道，Claude 用户现在可以把对话中制作的 Artifacts 安装为 Mac 或 Windows 桌面应用。功能处于 **beta**，需要最新版 Claude 桌面客户端和 Claude 账户；免费账户也能使用。报道列举的系统能力包括菜单栏项目、透明窗口和通知，应用也可调用连接器与 Claude。

这降低了从一次性原型变成常驻工具的门槛：用户不必每次先回到原始对话，软件也能接入更多桌面交互。不过，安装便利不等于应用天然可靠或可独立分发。报道提到 Apple Developer 账户等额外条件，具体能力和发布路径需要按平台核对。

对应用创业者而言，新的竞争面不是“生成界面”本身，而是权限管理、持续维护和真实工作流是否比临时生成的个人工具更好。桌面入口扩大了生成式软件的触达面，也让这些传统软件问题重新变得重要。

来源：[The Decoder 原文](https://the-decoder.com/anthropic-turns-claude-artifacts-into-standalone-desktop-apps-for-macos-and-windows/)

## 英伟达展示 Microduck 避障训练流程，保留既有步态策略

英伟达研究人员在 Hugging Face 发布 Microduck 避障教程：**固定已有步行策略权重**，再利用飞行时间（ToF）传感器训练单独的避障控制器。玩家仍通过手柄给出移动方向，控制器根据障碍情况调整速度指令，随后交给原有步行策略执行。

教程使用 Isaac Lab 进行仿真训练，用 Newton 模拟物理与深度传感，覆盖场景构建、训练、评估、导出及实机部署准备。这个架构的实际启发是把“能走稳”和“绕开障碍”拆成两个可分别调整的模块，而不是每增加一种能力都重新训练整套步态。

但这是一份厂商技术教程，不是跨场景独立对比试验。仿真到实机的迁移质量、不同障碍物和光照条件下的可靠性，以及实际维护成本，仍需结合实机结果评估。它更适合作为机器人团队的工程路径参考，而不是通用避障已解决的证据。

来源：[NVIDIA 技术文章](https://huggingface.co/blog/nvidia/microduck-obstacle-avoidance)

## 千一至感完成超千万元种子轮融资，瞄准宠物健康监测

据 Z Potentials 独家报道，北京千一至感科技有限公司完成 **超千万元种子轮融资**，由水木创投领投，全球健康产业创新中心跟投。公司计划将电磁感知与 AI 技术用于宠物健康硬件，首款面向北美市场的智能项圈 Kinsora One 据报道处于量产后期。

报道的产品思路是从定位和活动记录进一步走向生理状态监测；这也是有毛发遮挡、佩戴位置变化的消费场景。公司所述技术路线和市场判断仍需要独立验证，尤其不能把健康提醒直接等同于临床诊断能力。融资金额仅披露为超过千万元，估值和收入未在已核对材料中明确。

对这个项目，下一步比实验室指标更关键的是持续佩戴时的数据质量、对不同犬种的适配、售后与渠道成本，以及用户是否愿意为持续服务付费。量产后期意味着产品离交付更近，不代表已经形成规模化销售。
